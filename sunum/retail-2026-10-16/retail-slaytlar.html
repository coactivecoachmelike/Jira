Hesaplama Varsayımları

Kapsam
  • Sprint: Sprint 4 · 55 GitHub işi değerlendirildi.
  • Hariç tutulanlar: statüsü Backlog olan ve RetroAction etiketli işler — bu sprintte: #376.
  • Tüm slayt ve metrikler bu kapsam üzerinden hesaplanır.
Sayım birimleri
  • Xurrent talebi: aynı Xurrent Talep No'ya sahip GitHub işleri tek talep sayılır (BE/FE/App/Web parçaları); talep, tüm işleri bitince tamamlanmış sayılır.
  • Ek talep: Xurrent Talep No'su boş GitHub işi; her biri ayrı sayılır.
  • GitHub işi: panodaki her issue. Planlanan vs. tamamlanan toplamı ve iş tipi kırılımı bu birimle hesaplanır; bu yüzden talep sayısından büyük olabilir.
  • Xurrent statü dağılımında talep, işleri içinde en geride kalanın statüsünde sayılır; "Karşılık gelen GitHub işi" o talebe bağlı işlerin adedidir.
Statüler ve kolonlar
  • Tamamlandı sayılan statüler: Done, Released (lejantta ✓).
  • Kanban kolonları — Yapılacak: Todo · Geliştirmede: In Progress, Review · Test: Test, UAT · Tamamlandı: Done · Canlıda: Released.
  • Bir talebin rengi/kolonu, işleri içinde en geride kalanın statüsüdür.
İş tipi
  • Başlıkta [BUG] → Bug; DD Project Name dolu → Proje işi; toplantı, analiz/inceleme, deployment, kurulum, operasyonel işler → Task; diğerleri → User Story.
  • GitHub'ta issue type sütunu dışa aktarılırsa doğrudan o kullanılır.
Etiket bazlı metrikler
  • Sprint ortasında gelen iş = "AddedMidSprint" etiketli işler ÷ etiketsiz (ilk planlanan) işler.
  • Teknik borç payı = "TB" etiketli işler ÷ toplam iş.
  • Etiket karşılaştırmasında büyük/küçük harf, boşluk, - ve _ yok sayılır.
Lead time
  • Yalnız Done ve Released işler; süre takvim günü olarak sprint başlangıcından Closed tarihine kadar ölçülür.
  • Başlangıç: Original Sprint doluysa o sprintin, değilse işin sprintinin başlangıcı. Tanımlı başlangıç: Sprint 4=2026-10-05; diğer sprintler 14 günlük sprint varsayımıyla bulunur.
  • Closed tarihi boş olduğu için hariç: #620, #452, #521, #569.
Canlıya çıkış
  • Release bekleyen = statü Done + Ready For Release / WaitingRelease etiketi.
  • Canlıya alınan = kanbandaki "Canlıda" kolonundaki tüm işler (etiketten bağımsız).
  • Talebin yalnız bir kısmı canlıdaysa o işler GitHub başlığıyla ve ↳ notuyla listelenir.
Diğer
  • Original Estimate boş olan 11 iş 0 sayılır (yalnız Takıma özel slaytı etkiler).
  • Önceki sprintten aktarılan: Original Sprint, işin sprintinden farklıysa (↪ Sprint N).
  • Madde adları, GitHub başlıklarından iş birimi diline çevrilmiş tema adlarıdır; teknik ayrıntı için Xurrent / GitHub numarasına bakılabilir.
